# Field & Trim — GitHub Pages package

1. Create a GitHub repository and upload every file in this folder.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, then choose the `main` branch and the `/ (root)` folder.
4. Save. GitHub will give you a public URL in a few minutes.

## Contact email

Open `index.html` and replace `hello@your-business.com` with the email address that should receive lawn-care requests. The form opens the visitor’s email app with the request pre-filled, which works on static GitHub Pages hosting without a database.
